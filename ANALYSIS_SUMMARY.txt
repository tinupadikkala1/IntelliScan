KEY WORKFLOWS
================================================================================

1. FILE INDEXING (7-stage pipeline)
   File → MetadataExtractor → ContentExtractor → Chunking →
   Embedding → VectorStorage → Database → Signals

   Performance: 1-5 sec/file (depends on modality)
   Bottleneck: Video/audio processing (30 sec+ per file)

2. SEMANTIC SEARCH (5-stage retrieval)
   Query → Embedding → VectorSearch → Hydration →
   Filtering & Ranking → Results

   Performance: 50-200 ms typical
   Indexed: 10,000+ files searchable

3. RAG QUESTION ANSWERING (6-stage pipeline)
   Query → Intent Detection → Context Retrieval →
   Ranking → PromptBuilding → LLM Generation → Citations

   Performance: 2-10 sec (1-5 sec with caching)
   Fallback: Search-only mode if LLM unavailable

4. FILE ORGANIZATION (4-stage clustering)
   Discovery → Classification → Folder Generation →
   Safe Movement with DB Sync

   Performance: 10-30 sec for 1000 files
   Safety: Atomic operations, collision detection

5. DUPLICATE DETECTION (4-stage grouping)
   Discovery → Exact/Near Duplicate Finding →
   Scoring & Ranking → Suggestion Generation

   Performance: 5-30 sec for 10K files
   Thresholds: SHA-256 exact, CLIP 0.15, semantic 0.5
